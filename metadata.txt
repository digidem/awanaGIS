about=AwanaGIS adds a chat dock to QGIS. Type a request in natural language and an LLM agent carries it out by generating and running PyQGIS code, giving it access to QGIS, Processing, project layers, installed plugins, and Brazilian/Indigenous public spatial data tools (br_*, bundled GISBR GPL-3.0 plus curated FUNAI/DSEI/INPE adapters). Requirements: QGIS 3.22 or newer (including QGIS 4) and an LLM connection using a provider API key, compatible custom endpoint, or installed local CLI agent. Google Earth Engine features are optional and require the Google Earth Engine QGIS plugin to be installed and authenticated separately. Derived from AgenticGIS by Muhammad Alichamdan (GPL-2.0-or-later), bundling adapted GISBR modules (GPL-3.0); combined distribution under GPL-3.0-or-later.
