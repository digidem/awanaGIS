Have each agent read its full documents and reference files. Inspect current HEAD and preserve existing work. 2. **Make branding P0 and the first integration gate.** Build the independent AwanaGIS identity, UI/brand, settings/MCP isolation, preserved PT-BR, attribution and installable QGIS ZIP **first**. Test it and deliver a **branding-only release candidate suitable for us to review/upload** as soon as ready, without waiting for the other feature lanes. Do not publicly publish/upload it without explicit owner approval.
3. **Meanwhile**, implement GISBR/Indigenous sources and SMP planning/export in their own worktrees. They may use the existing AgenticGIS APIs internally while developing; before integration they must adapt to AwanaGIS identity, preserve branding and translations, and avoid duplicate providers or altered permission semantics. Respect Indigenous-data restrictions and SMP render-layer consent.
4. After the branding gate passes, **integrate onto the branded branch** (cherry-pick/merge/rebase as appropriate), resolve conflicts centrally, run all available automated/QGIS tests and package a consolidated AwanaGIS ZIP. Report PASS/FAIL/NOT RUN truthfully. Keep the Git repository's `docs/` tracked despite inherited ignore rules.
5. **Create one final pull request in our AwanaGIS repository** against its default/integration target branch (inspect remotes; never guess the repo or submit upstream). PR description: summary by feature, original upstream code/license notices, security considerations, screenshots where useful, tests with commands/results, limitations, and links to both the **branding-only** and **combined** build artifacts. If PR permissions are unavailable, leave a ready branch and exact PR link/command instead of claiming it was opened.

Prioritize a **working, uploadable branded plugin** over polish in the later integrations. Finish real code and tests, not another planning document. Do not reset or overwrite uncommitted work; do not force-push, release publicly, or submit to QGIS Plugin Repository without explicit authorization.
